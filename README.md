Fate Mirror｜命运镜像 
一款将塔罗牌转化为自我提问与反思体验的双语互动网页
个人项目

项目简介
Fate Mirror 是一个以塔罗牌为媒介的双语自我探索网页。我尝试重新思考塔罗体验的意义：与其直接给出命运预测，不如通过提问、牌阵选择、抽牌与解读，帮助用户整理困惑，并从新的角度观察自身处境。
用户可以输入当前面对的问题，选择适合的牌阵，再通过互动抽牌获得牌位启示、整体解读、潜意识模式、行动建议和延伸自省问题。项目将塔罗象征体系与循序渐进的交互流程结合，希望把一次简单的“抽牌”转化为一段更有参与感的自我对话。
设计出发点
人在面对关系、创作或人生选择时，往往希望尽快得到明确答案。但一个结论未必能帮助人理解困境背后的真实需求。
因此，我提出了一个设计问题：
能否把塔罗从“预测答案”的工具，转化为引导用户主动提问和自我观察的互动媒介？
我以“镜像”作为核心概念：牌卡不是替用户决定未来，而是提供象征性的观察角度，帮助用户重新组织问题、识别情绪，并思考可以采取的下一步行动。


核心体验流程
项目通过五个阶段引导用户完成一次自我探索：
提问｜ASK
用户输入当前的困惑或现实议题，为后续体验建立个人语境。
选择牌阵｜MODE
用户根据问题选择不同的观察结构，包括每日单牌、问题／阻碍／建议、过去／现在／未来、关系镜像和凯尔特十字。
感知｜SENSE
用户进入仪式化的交互空间。项目提供鼠标操作，也设计了基于摄像头手部追踪的手势交互入口。
抽牌｜DRAW
用户在轨道式牌卡空间中浏览并抽取卡牌，完成对应牌阵的抽取。
解读｜READ
用户查看牌位含义、整体解读、潜意识模式、行动建议与自省问题，将象征信息转化为进一步思考的线索。

视觉设计
我以“镜像、轨道与仪式”为视觉线索，采用深色背景、金色细节、圆形轨道和牌卡图像构建统一的界面氛围。版式和文案兼顾操作指引与叙事表达，让视觉不仅装饰页面，也帮助用户理解当前所处的体验阶段。
交互设计
我将体验拆分为连续的步骤，并为每个阶段安排清晰的任务与反馈。牌阵选择帮助用户建立不同的观察框架；牌卡浏览与抽取让用户参与结果形成；最终解读则把体验带回用户自己的问题。
在输入方式上，项目提供鼠标操作，并探索基于手势的无接触式交互。鼠标路径让用户可以直接完成主要流程，手势交互则扩展了与牌卡空间互动的方式。
技术实现
前端使用 Vite 构建流程组织和打包网页资源，使用 Tailwind CSS 工具类与自定义 CSS 实现界面布局、视觉样式和动效。手势交互部分集成 MediaPipe Hands 与 MediaPipe Camera Utils，用于浏览器端手部追踪及摄像头输入。网站部署于 Vercel。
